EasyRep 모델 개발 목표

객체 탐지 본체, 탈피 임박·진행 상태, 개체별 미래 탈피 시기 예측을 각각 실제 학습하고 검증한다. 기존 좋은 탐지기를 유지하며 개선 후보만 별도로 평가한다. 개인 일지·카메라·PC 연결·배터리 잔량은 선행조건이 아니다. 전체 목표는 아직 미완료다.

- prepared_not_executed protocol은 실행 허가가 아니다. 외부 호출 전에는 같은 폴더의 completion-review.json·closure.json·queue.json을 먼저 읽어 완료/폐쇄 여부와 exact query·URL을 대조한다. 충돌하면 closure/completion이 우선이며, 이미 닫힌 query를 재호출하지 않는다.
- 실행 중이면 정확 PID/create-time과 기존 결과부터 확인한다. 채팅 만료·세션 관측 실패를 프로세스 종료로 간주하거나 같은 작업을 다시 시작하지 않는다.
- 2026-11-14 사용자가 기존 Goal을 지운 뒤 새 목표 설정을 명시했다. get_goal의 goal=null을 확인하고 create_goal이 두 모델 실제 학습·평가 목표의 active를 반환했다. 이전 usageLimited는 과거 상태이며 완료를 뜻하지 않는다. easyrep 자동화는 삭제 상태를 유지한다.

탈피 상태와 시기
- 현재 상태(임박/피부 탈락 중)와 미래 시기(다음 시작·완료까지 남은 시간)는 별도 타깃이다. 상태 분류를 날짜 예측으로 보고하지 않는다.
- 크레스티드 또는 유사 개체의 실제 반복 탈피 날짜·동일 개체 확인·탈피 전 원본 사진·촬영/가용 시각·미디어 권리를 직접 확보한다. 기록만, 이미지만, 결합 모델을 같은 사전 고정 시간/주기/개체 분할에서 학습·평가한다. 적격 자료를 확보하면 기존 intake/timeline/cohort/predictor/evaluator를 재사용해 바로 학습으로 연결한다.
- 같은 개체·몸 부위·비교 가능한 조건의 색·채도·명도·질감 변화/지속 시간, 마지막 확인 탈피 경과, 시각/quality가 맞는 행동·온습도를 사용한다. IR·젖음·조건/개체 불명은 색 특징에서 제외한다.
- 관측하지 않은 날을 음성으로 만들거나, 색 변화만으로 탈피 날짜를 정하거나, 다른 개체의 사진과 날짜를 합치지 않는다. 불확실/부분 탈피·주관적 설명·가용 시각을 보존한다. 프레임 수는 독립 주기 수가 아니다.
- 단순 주기 기준선과 비교해 미래 주기·별도 개체의 오차, 누락, 오경보, 선행 시간, 보류율 및 제공된 확률의 보정을 평가한다. RGB 없는 간격 모델, 주관적 whitening 특징, 다른 종 모델을 색 기반 크레스티드 성능으로 확대하지 않는다.
- 기존 실제 상태/날짜 모델 학습은 각 completion-review에 보존돼 있다. 현재 새 크레스티드 반복날짜+검수RGB의 세 모달 비교는 미검증이다. 학습 자료 부족을 합성 자료·가짜 라벨·새 UI/모듈·검색 건수로 채우지 않는다.

행동 분류
- 객체 탐지와 행동 분류는 별도 모델로 둔다. 탐지·추적으로 만든 시간창과 사람이 확정한 행동 구간을 연결해 `moving`·`resting` 등 명시적 상태만 학습하고, 기록 그룹 단위로 미래 평가를 분리한다.
- 검출 누락·가림·부분 가시성·불확실·미라벨은 상태 음성이나 `resting`으로 바꾸지 않고 `unobserved`로 보류한다. v1 이동특징 분류기는 빠른 기준선이며, 자세·이미지 기반 행동 모델은 라벨·권리·시간순 원본이 확인된 뒤 별도 후보로 학습·비교한다.
