# 모델

학습·추론 코드는 `../behavior-recorder/`에 있습니다. 모델 관리 기록은
`../behavior-recorder/MODEL_STORAGE.md`를 참고하세요.

`local-artifacts.json`은 통합 시점의 로컬 가중치·학습 산출물 목록입니다.
후보·중간 산출물이 함께 포함되어 있어 운영 모델 목록이나 성능 보증을 뜻하지 않습니다.
가중치 파일 자체와 학습 데이터는 이 첫 소스 게시에 포함하지 않았습니다.
실행에는 해당 설정이 참조하는 파일을 별도로 준비해야 합니다.

배포할 모델을 정한 후 GitHub Release 또는 모델 저장소에 올리고,
다운로드 주소·SHA-256·사용 조건을 함께 기록합니다.
