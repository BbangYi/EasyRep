# 공간 온도 추정과 열부하 계산

이 모델은 **센서가 없는 위치의 온도를 추정**하고, 별도의 계산으로 **냉난방에 필요한 열량을 검토**하는 데 사용합니다. 두 기능 모두 정해진 수식을 사용하므로 학습 가중치 파일이 필요하지 않습니다.

## 입력하면 무엇이 나오나요?

| 기능 | 입력 | 출력 |
|---|---|---|
| 공간 온도 추정 | T1·T2·T3 온도, 측정 시각, 센서 위치 | 사육장 안 각 위치의 추정 온도 |
| 열부하 계산 | 사육장 크기, 안팎의 온도 차이, 환기·수분 변화 등의 가정 | 냉난방 부하(W), 이슬점, 전력 검토값 |

예를 들어 세 센서가 각각 26.0°C, 25.0°C, 24.5°C를 측정했다면, 공간 모델은 센서 사이와 주변의 온도를 계산해 화면에 표시합니다. **이 숫자는 설명용 입력 예시입니다.** 화면에 색으로 표시한 전체 공간이 모두 센서로 측정된 것은 아닙니다.

## Pi에서 어떻게 연결되나요?

```text
ESP32의 온도 측정 → Pi의 데이터 검증 → 공간 온도 계산 → 화면 표시
```

현재 공간 모델은 **20×20×30 cm 사육장만 지원**합니다. 처음에는 가까운 센서에 더 큰 비중을 주어 온도를 채웁니다. 다음 측정이 들어오기 전까지는 가정한 공기 이동·열 확산·벽면 열교환을 계산하고, 새 측정이 들어오면 그 차이를 반영해 수정합니다. 수신이 오래 끊겼다가 돌아오면 다시 초기화합니다.

계산은 2 cm 간격으로 하고, 화면에는 1 cm 간격으로 더 촘촘하게 표시합니다. 표시 간격을 줄였다고 측정 정확도가 높아진 것은 아닙니다. 풍속·벽면 조건·기본 센서 위치에는 가정이 포함되어 있고, 공간 전체의 정확도는 아직 검증되지 않았습니다. 현재 모델은 습도 분포·미래 온도·동물 체온을 계산하지 않습니다.

## 지금 로컬에서 확인하기

저장소 최상위 폴더에서 Python 3으로 다음 명령을 실행하면 열부하 계산 결과가 나옵니다. 외부 장치 연결이나 GPU는 필요하지 않습니다.

```sh
python3 gateway/docs/hardware-design/thermal-sizing.py
```

이 명령은 가정한 조건의 계산값만 출력하며 장치를 제어하지 않습니다. 나온 수치를 측정 결과나 동물의 적정 사육 조건으로 해석하지 않습니다. Pi 실시간 화면 설치는 [Gateway 안내](../../gateway/README.md)를 따릅니다.
