# 모델 안내

이 폴더는 **어떤 계산 모델이 있고, 실행에 어떤 파일이 필요한지** 정리하는 곳입니다. 모델마다 준비 상태가 다르므로 아래 표에서 먼저 확인하세요.

| 폴더 | 하는 일 | 현재 들어 있는 것 |
|---|---|---|
| [thermal-air](thermal-air/) | 세 지점의 온도로 공간 온도를 추정하고, 별도 수식으로 냉난방 부하를 계산 | 코드 위치·수식·가정 안내. 학습 가중치는 필요 없음 |
| [environment-mlp](environment-mlp/) | 온습도 이력과 분무 계획을 보고 앞으로의 변화를 예측 | 학습·예측 코드 안내와 파일 목록. **최종 가중치와 학습 보고서는 원본 확인 대기** |
| [lizard-hybrid-hinge-v1](lizard-hybrid-hinge-v1/) | 도마뱀 탐지 과정에서 후보를 판별하고 점수를 결합 | 작은 학습 결과 `verifier.json`, `joint.json`. 대형 탐지기·특징 추출기 파일은 별도 필요 |

## 코드와 가중치는 무엇이 다른가요?

**코드**는 계산 순서와 방법입니다. **가중치**는 AI가 학습하면서 얻은 숫자들을 저장한 파일입니다. AI 모델은 코드가 있어도 맞는 가중치가 없으면 기존 학습 결과로 예측할 수 없습니다. 반면 `thermal-air`처럼 정해진 수식을 계산하는 모델에는 학습 가중치가 없습니다.

각 폴더의 `manifest.json`은 파일 목록과 확인 정보를 기록합니다. `sha256`은 파일이 같은지 대조하는 검사값입니다. 값이 `null`이거나 상태가 `pending`이면 아직 확인된 파일로 취급하지 않습니다.

## 프로그램과 연결되는 위치

- 환경·열 계산 코드는 [`gateway/`](../gateway/)에 있습니다. Pi의 센서 처리, 공간 온도 표시, 별도 GPU의 환경 예측과 연결됩니다.
- 영상·행동 분석 코드는 [`behavior-recorder/`](../behavior-recorder/)에 있습니다. 환경 MLP와는 다른 모델입니다.
- 이 폴더에는 실행 코드를 다시 복사하지 않습니다. 각 모델 안내에서 원래 코드로 이동할 수 있습니다.

기존 영상 모델의 [평가 요약](RESULTS.md)과 [집계 자료](evaluation-summary.json)는 당시 실험 결과입니다. 모든 분석 기능이나 실제 사육장 성능이 검증됐다는 뜻은 아닙니다. 필요한 외부 모델 파일을 준비한 뒤 [기존 패키징 도구](../behavior-recorder/scripts/package_hybrid_model.py)를 사용합니다.

원본 영상·학습 데이터·중간 학습 파일은 여기에 쌓지 않습니다. 환경 모델의 계산값과 예측값도 실제 센서 측정값이나 장치 제어 승인과 구분합니다.
